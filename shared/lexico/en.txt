# Lexico anti-vicios de IA, ingles. Lido por scripts/lint_copy.py.
#
# FORMATO (estavel, nao mude sem atualizar o lint):
#   ID | padrao | sugestao | modo
#
#   ID        regra do catalogo em docs/pesquisa/pesquisa-vicios-ia-email.md
#             (C12, C16, C17, C20, C21, C22, C23, C24, C25, C26)
#   padrao    tres formas aceitas:
#               texto literal   casa sem acento e sem caixa, com borda de palavra
#               radical*        casa o radical mais ate 3 letras (plural, flexao)
#               re:expressao    expressao regular, IGNORECASE, sobre o texto original
#   sugestao  o que escrever no lugar. Aparece na saida do lint.
#   modo      opcional. "unitario" (padrao): 1 ocorrencia ja acusa.
#             "densidade": so acusa com 3 ou mais ocorrencias do mesmo ID no e-mail.
#
# Linha vazia e linha iniciada por # sao ignoradas. Espaco em volta dos campos
# e ignorado. Os campos sao lidos das pontas para o meio (ID na esquerda, modo e
# sugestao na direita), entao o padrao pode conter | de alternancia de regex.
#
# Esta lista e viva: entrada nova precisa de um caso em scripts/tests/.
# Ao adicionar, confira antes a lista de falso positivo em shared/calibracao.md.
